# 模範解答

## (1) 正解：**C**

#### この問題で確認したいこと

`short` の左辺値では、`int` への変換が必要な非テンプレートより、仮引数が `short&` になるユニヴァーサル参照が選ばれ、その本体が不適格なら呼び出しも不適格になることを確認する。

#### 解説

`nameIdx` は非const の `short` 左辺値であり、ユニヴァーサル参照の仮引数は `short&` である。これは完全一致である。`logAndAdd(int)` は `short` から `int` への変換が必要で、適合度は完全一致より低い。

適合度が異なるため、高い側のユニヴァーサル参照が選ばれる。非テンプレートであることは、この比較には使わない。選ばれた特殊化は `names.emplace` で `short` から `std::string` を構築しようとする。そのコンストラクタはないので、本体は不適格であり、呼び出しを含むプログラムも不適格である。本体が不適格でも解決はやり直されず、`logAndAdd(int)` は選ばれない。

|選択肢|判定|理由|
|-------|-------|-------|
|A|×|適合度が異なるとき、非テンプレートかどうかは比較に使わない|
|B|×|`short&` は完全一致であり、`int` への変換とは適合度が同じではない|
|C|○|完全一致のユニヴァーサル参照が選ばれ、`short` から `std::string` を構築できずに不適格になる|
|D|×|選ばれた特殊化の本体が不適格でも、次点の `logAndAdd(int)` には進まない|

## (2) 正解：**A**

#### この問題で確認したいこと

非const の `Person` 左辺値からの直接初期化では、`const` を付加するコピーコンストラクタより、仮引数が `Person&` の転送コンストラクタが選ばれ、初期化が不適格になることを確認する。

#### 解説

`original` は非const の左辺値である。転送コンストラクタの仮引数は `Person&` であり、完全一致である。コピーコンストラクタの仮引数 `const Person&` でこの引数を受けるには `const` の付加が必要で、適合度は完全一致より低い。

そのため転送コンストラクタが選ばれ、コピーコンストラクタは選ばれない。`name` を `Person` から初期化するコンストラクタはないので、選ばれた特殊化の本体は不適格であり、`Person copy(original)` は不適格である。コピーコンストラクタをクラスに書いてあっても、この比較の結果は変わらない。

|選択肢|判定|理由|
|-------|-------|-------|
|A|○|`Person&` が `const Person&` より適合度が高く、転送コンストラクタの本体が不適格になる|
|B|×|`const` の付加が必要な束縛は完全一致より適合度が低く、同順位の扱いにならない|
|C|×|転送コンストラクタの本体が不適格でも、コピーコンストラクタへは解決し直されない|
|D|×|適合度が高いのは `const` を付加しない `Person&` の側である|

## (3) 正解：**D**

#### この問題で確認したいこと

const の `Person` 左辺値からの直接初期化では、転送コンストラクタとコピーコンストラクタの適合度が同じになり、非テンプレートのコピーコンストラクタが選ばれて適格になることを確認する。

#### 解説

`original` は const 左辺値である。転送コンストラクタの仮引数は `const Person&`、コピーコンストラクタの仮引数も `const Person&` であり、どちらも完全一致である。適合度は同じである。

適合度が同じとき、非テンプレート関数が関数テンプレートより優先される。呼び出しは曖昧にはならない。したがってコピーコンストラクタが選ばれ、`name` はコピーされる。この初期化は適格である。転送コンストラクタは選ばれないので実体化されず、`const Person` から `std::string` を初期化する処理はプログラムに現れない。

|選択肢|判定|理由|
|-------|-------|-------|
|A|×|適合度が同じときは、関数テンプレートではなく非テンプレートが優先される|
|B|×|適合度が同じでも曖昧にはならず、非テンプレートのコピーコンストラクタが選ばれる|
|C|×|仮引数はどちらも `const Person&` であり、転送コンストラクタの方が高いわけではない|
|D|○|同順位では非テンプレートのコピーコンストラクタが選ばれ、`name` のコピーとして適格である|

## (4) 正解：**B**

#### この問題で確認したいこと

派生クラスのコピーコンストラクタが基底を初期化するとき、派生から基底への変換が必要なコピーコンストラクタより、仮引数が派生クラスの参照になる転送コンストラクタが選ばれ、その初期化が不適格になることを確認する。

#### 解説

式 `rhs` は `const SpecialPerson` の左辺値である。`Person` の転送コンストラクタの仮引数は `const SpecialPerson&` であり、完全一致である。`Person(const Person&)` でこの引数を受けるには、派生クラスから基底クラスへの変換が必要で、適合度は完全一致より低い。

そのため転送コンストラクタが選ばれ、基底のコピーコンストラクタは選ばれない。非テンプレートであることは、適合度が異なるこの比較には使わない。選ばれた特殊化は `name` を `SpecialPerson` から初期化しようとする。そのコンストラクタはないので、`: Person(rhs)` は不適格である。

|選択肢|判定|理由|
|-------|-------|-------|
|A|×|派生から基底への変換は完全一致より適合度が低く、同順位ではない|
|B|○|`const SpecialPerson&` の転送コンストラクタが選ばれ、`std::string` を `SpecialPerson` から初期化できずに不適格になる|
|C|×|適合度が異なるとき、非テンプレートかどうかは比較に使わない|
|D|×|転送コンストラクタの本体が不適格でも、基底のコピーコンストラクタへは解決し直されない|
